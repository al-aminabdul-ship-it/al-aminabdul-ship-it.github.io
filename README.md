# Al-Amin B. Abdul — Portfolio

This is a plain static portfolio site for GitHub Pages. It uses only HTML, CSS, and vanilla JavaScript, so there is no build step or package manager.

## Folder structure

- `index.html` — semantic page content and project links
- `style.css` — responsive light/dark theme and accessibility styles
- `script.js` — mobile navigation and image lightbox behavior
- `images/` — favicon, profile photo, and project screenshots
- `docs/` — resume and project reference PDFs

Open `index.html` directly in a browser for a local preview, or publish the repository as a GitHub Pages site.
